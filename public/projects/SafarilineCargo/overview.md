## Product Overview

Cargo moves through many hands. The interface needs to keep the whole journey understandable.

I developed both the web and mobile applications for Safariline Cargo. The web console brings air and sea operations into one workspace: waybills, manifests, warehouse facilities, tracking, customer and supplier accounts, approvals, and reports. The mobile application supports arrival confirmation, cargo selection, dispatch, receiving, and shipment lookup. The web dashboard introduces the product with a clear promise: **Movement made visible.**

## User Need

Operations teams need to answer practical questions quickly: where is the cargo, which branch holds it, what stage has it reached, and which records need attention? A shared navigation system connects those questions to the relevant shipment, facility, or account.

## Product Experience

- **Start with the network.** A branch-aware overview combines shipment counts, freight modes, recent activity, and shortcuts to tracking and reporting. All-branch access is explicitly presented as read-only.
- **Find the waybill.** The shipment register brings route, volume, manifest, and status together, with filters for origin, destination, freight mode, and shipment status.
- **Connect the web desk to mobile operations.** The web console shows warehouse facilities and stock volumes, while the mobile application supports arrival confirmation, cargo selection, dispatch, receiving, and shipment lookup.
- **Connect operations to accounts.** Customer and supplier sections sit alongside reporting for statements, payments, route revenue, shipment status, and warehouse dwell.

## Outcome

Connected web and mobile applications that bring shipment movement, warehouse activity, and financial records into a shared operations experience. The case study shows both products through the web console overview and dedicated web and mobile video walkthroughs.
