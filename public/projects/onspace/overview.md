# Product Overview

OnSpace replaces spreadsheets and chat threads with structured workflows for distributed teams. The platform centralizes data collection, team communication, and reporting.

## User Need

Operations teams needed one system to collect field data, coordinate work, and report progress without switching tools.

## Product Experience

- Dynamic form builder for structured data collection.
- Team chat and collaboration views.
- Data visualization dashboards for reporting.
- Responsive UI that works across desktop and mobile.

## Role

Frontend Developer

## Outcome

- Delivered a single interface that centralizes data collection, collaboration, and reporting.

# Tech Stack

- React, Flutter, Dart
- Firebase, PostgreSQL, GraphQL
