# Product Overview

Hbnb is an AirBnB-style product with dynamic listings, filters, and a REST API.

## User Need

Users needed to browse listings, filter by amenities, and see results without full page reloads.

## Product Experience

- Dynamic listings rendered from a Flask REST API.
- Filters for locations and amenities with AJAX updates.
- Live API status indicator in the UI.

## Role

Personal Project

## Outcome

- Delivered a full-stack prototype that demonstrates API-driven UI updates.

# Tech Stack

- Python, Flask, MySQL
- jQuery, AJAX
