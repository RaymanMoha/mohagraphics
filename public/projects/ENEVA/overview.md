# Product Overview

ENEVA is a utility bills manager for electricity and water services. The mobile app combines bill tracking, meter capture, and usage history in one place.

## User Need

Users needed a single mobile experience to track bills, submit meter readings, and review usage history without switching tools.

## Product Experience

- Bill tracking and account views for electricity and water.
- OCR meter capture to reduce manual entry.
- Cloud-backed sync and analytics for usage history.

## Role

Flutter Mobile Developer

## Outcome

- Shipped a cross-platform mobile app with OCR capture and cloud data services.
- Published on Google Play.

# Tech Stack

- Flutter, Dart
- Firebase, GCP, BigQuery
- OCR pipeline
