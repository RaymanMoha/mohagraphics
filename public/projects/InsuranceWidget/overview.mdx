# Product Overview

InsuranceWidget is a quote calculator and onboarding flow designed for insurance providers to embed on their sites.

## User Need

Users needed a guided, step-by-step quote experience that works on mobile and can be embedded on partner websites.

## Product Experience

- Multi-step onboarding flow for collecting applicant details.
- PWA support for install and offline access.
- Iframe embedding for partner sites.

## Role

Frontend Developer

## Outcome

- Delivered a production-ready prototype with PWA and embed support.

# Tech Stack

- React, TypeScript, Vite
- Redux, Styled Components
- PWA
