# Product Overview

Mobile and web interface work under Reon Capital spanning football ticketing, venue access, utility management, shopping, fuel commerce, and developer onboarding.

## User Need

Different users needed different interfaces: fans finding tickets, gate staff checking entry, households managing utilities, shoppers browsing products, and developers accessing a portal. Each experience needed to make the relevant task clear.

## Engineering Focus

- Contributed mobile interface work across the Reon Capital app portfolio, with each app supporting a distinct user journey.
- Worked across Zuba, Zuba Steward, Eneva, ANSU, and Sava, with project details distinguishing the scope of each product.
- Included Developer Hub web work for branded sign-in and account creation flows.
- Presented the apps as one portfolio while keeping each project's role, scope, and release evidence visible.

## Outcome

Four apps have public Google Play listings: Zuba, Zuba Steward, Eneva, and ANSU. Sava is represented by project interface screens and did not launch on Google Play. Developer Hub is a web experience. Store listings demonstrate the apps' published state; they do not imply sole authorship of the full products.
