# Product Overview

Zuba is a digital platform for the Botswana Premier League. The product includes a fan app and a steward operations app connected to live match data.

## User Need

The league needed a modern fan experience and a separate tool for match-day operations, both tied to real-time fixtures and results.

## Product Experience

- Fan app with fixtures, live scores, news, and notifications.
- Steward app for match reporting, incident tracking, and coordination.
- Real-time data integration for fixtures and results.

## Role

Mobile Developer

## Outcome

- Shipped two production mobile apps tied to shared data services.
- Published both apps on Google Play.

# Tech Stack

- Flutter
- Firebase
- Node.js
- Real-time APIs
