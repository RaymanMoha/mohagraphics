# Product Overview

QuickHost provides web hosting and domain registration services in Kenya. The website clarifies plans and guides users to the right service.

## User Need

Customers needed a simple way to compare hosting options and move to purchase without confusion.

## Product Experience

- Homepage structure that highlights domains, hosting, and cloud services.
- Service sections with clear calls-to-action.
- Responsive layout optimized for mobile and desktop.

## Role

Frontend Developer

## Outcome

- Delivered a service-led navigation structure for faster decision making.

# Tech Stack

- WordPress
- Tailwind CSS
- Figma
- Google Analytics
